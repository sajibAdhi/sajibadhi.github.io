# Professional IDE Portfolio

A high-fidelity, VS Code-themed portfolio built with **Vue 3**, **TypeScript**, and **Tailwind CSS**. This project showcases a Software Engineer's profile, experience, and technical skills within a professional integrated development environment (IDE) interface.

## 🚀 Quick Start

### Prerequisites
- **Node.js** (v18 or higher)
- **npm** (v9 or higher)

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/sajibAdhi/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

## 🛠 Tech Stack
- **Frontend:** Vue.js 3 (Composition API)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Build Tool:** Vite
- **Deployment:** GitHub Actions (Automated)

## 📁 Project Structure
- `src/App.vue`: Main IDE interface and resume data.
- `src/style.css`: Custom Tailwind theme and IDE chrome styling.
- `.github/workflows/deploy.yml`: CI/CD pipeline for GitHub Pages.
